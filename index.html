Hi. I'm Mingi Jung

I am a Master's student at the Web Security Lab (WebSec Lab) at UNIST. My research focuses on Web Security and Browser Security, particularly on discovering emerging vulnerability classes and building automated systems to identify novel attack vectors. I am interested in applying program analysis and LLM-based techniques to both Static Application Security Testing (SAST) and Dynamic Application Security Testing (DAST).

Besides, I am an active CTF player and bug bounty hunter with a strong interest in practical offensive security techniques. I enjoy exploring diverse attack scenarios and experimenting with real-world exploitation techniques.
